
# Responsive Personal Portfolio Website

A professional and responsive personal portfolio website built using HTML5, CSS3, and JavaScript.

## Features

- Home section with personal introduction
- About Me section
- Technical Skills showcase
- Academic and personal projects
- Education and experience timeline
- Contact section with form validation
- Responsive navigation menu
- Mobile, tablet, and desktop layouts
- Smooth scrolling
- Automatic footer year

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Media Queries

## Project Structure

responsive-personal-portfolio/
|
|-- index.html
|-- style.css
|-- script.js

## How to Run

1. Download or clone this repository.
2. Open the index.html file in a browser.
3. Navigate through the portfolio sections.
4. Test the contact form validation.
